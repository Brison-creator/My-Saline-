A modern, fast, production-ready hyperlocal news theme built for MySaline.com.

== Description ==

MySaline is a classic (PHP) WordPress theme designed for a busy community news
site. It ships with dashboard-managed controls for everything an editor touches
day to day, and it is fully compatible with existing posts, pages, categories,
tags, authors, media, archives and permalinks.

Highlights:

* Featured stories hero (mark posts as "Featured" in the editor)
* Breaking-news bar (manual message or auto from a category)
* Configurable, category-driven homepage sections
* Advertisements custom post type with placement zones and run dates
* Community Events custom post type with dates, venue and ticket links
* Obituaries custom post type with service details
* Business Directory custom post type with categories and contact info
* Newsletter signup (Mailchimp / any provider — no code)
* Social links (Facebook, Instagram, X, YouTube, TikTok, LinkedIn, RSS)
* Editable logo, colors and branding via the Customizer
* Four footer widget columns, two sidebars and five custom widgets
* Translation ready, accessible, responsive, block-editor friendly

== Managing content ==

Everything is controlled from the WordPress dashboard. See
Appearance → MySaline Setup for a one-page map of every control, or read
docs/CONTENT-MANAGEMENT.md in the theme repository.

== Compatibility ==

The theme uses the standard WordPress template hierarchy, so existing content
and URLs continue to work unchanged. Custom post types add NEW content only and
never alter existing posts, pages or their addresses. If a custom post type slug
ever collides with an existing page, it can be changed with a one-line filter
(documented in docs/CONTENT-MANAGEMENT.md) — no core edits required.
