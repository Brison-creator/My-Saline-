This is sample body copy standing in for a real article, so you can see how the theme sets long-form text — measure, line height, and the spacing between paragraphs and subheads.

Running text sits at a comfortable reading width with Georgia used for headings and a system sans for body copy. Links inside paragraphs look like this, and the type scale stays consistent from the headline down to the captions.

Subheads break up longer stories

Section headings inherit the same serif as the headline at a smaller size, which keeps a clear hierarchy without introducing another typeface. Lists, pull quotes and embedded images all pick up the same treatment.

Pull quotes use the accent red on the rule, which ties article pages back to the breaking-news bar and the section headers.

An in-content ad zone can be placed automatically a few paragraphs in, so advertising stays part of the reading experience rather than crowding the top of the page.
